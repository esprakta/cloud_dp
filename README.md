# Дипломная работа: Облачное хранилище файлов

## Структура проекта:

- **cloud/** - бэкенд (Spring Boot + PostgreSQL)

- **netology-diplom-frontend/** - фронтенд (Vue.js)

## Запуск:

### Бэкенд:
cd cloud

docker-compose up

### Фронтенд:
cd netology-diplom-frontend

npm install

npm run serve
