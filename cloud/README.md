# Облачное хранилище файлов

## Описание
REST API для облачного хранилища файлов с авторизацией пользователей.

## Технологии
- Java 21
- Spring Boot 4.1.0
- Spring Data JPA
- PostgreSQL 16
- Docker & Docker Compose
- Vue.js (фронтенд)
- Testcontainers (тестирование)

## Требования
- Java 21+
- Docker & Docker Compose
- Node.js 18+ (для фронтенда)
